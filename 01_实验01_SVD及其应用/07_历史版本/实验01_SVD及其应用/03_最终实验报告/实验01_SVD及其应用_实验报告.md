### 1.3  SVD 与最优截断

对 A∈R^(m×n)，约化分解为 A=UΣVᵀ，σ₁≥…≥σᵣ≥0。U 的列是 AAᵀ 的特征向量，V 的列是 AᵀA 的特征向量，对应特征值为 σᵢ²。非方阵 A 本身没有通常意义的左右“特征向量”，本报告使用“左右奇异向量”。

A=Σᵢ σᵢuᵢvᵢᵀ；Aₖ=Σᵢ₌₁ᵏ σᵢuᵢvᵢᵀ。由正交性，||A−Aₖ||²_F=Σ_(i>k) σᵢ²。Aₖ 是 Frobenius 范数意义下的最优秩不超过 k 的近似。截断是数据相关的低秩近似，不等同于按傅里叶频率排序。

## 2  给定矩阵的分解与数值核对

### 2.1  组装约定

按 PDF 图像逐行转录 Q₅、Q₄、Σ 后，比较两种乘法。Q₅ΣQ₄ 与指导书印出的 A 的最大元素差为 3.276e-05，而 Q₅ΣQ₄ᵀ 的差为 41.700658。因此采用 A=Q₅ΣQ₄；此处 Q₄ 对应 Vᵀ。两者的小差异与指导矩阵只保留六位小数相符，未将输入擅自重新正交化。

### 2.3  两种算法交叉验证

教学实现先用 eigh 求 AᵀA 的特征对，取平方根得到 σᵢ，再按 uᵢ=Avᵢ/σᵢ 计算左奇异向量；参考实现使用 np.linalg.svd。两者奇异值最大绝对差 5.487e-11。秩一分量求和重构误差为 5.975e-14。

构造 AᵀA 会将条件数平方，因此该实现适合解释数学关系；小奇异值和左向量正交性更易受舍入影响，后续图像与人脸实验均直接用 SVD。奇异向量允许成对变号，同一 σᵢ 对应的 uᵢ、vᵢ 同时取负不会改变重构。附录给出本次输出的向量与全部秩一项。

## 3  图像压缩：实现与指标

### 3.1  灰度图三行核心代码

```python
A = img @ np.array([0.2126, 0.7152, 0.0722])
U, s, Vt = np.linalg.svd(A, full_matrices=False)
A_k = (U[:, :20] * s[:20]) @ Vt[:20, :]
```

输入 img 已转换为 [0,1] 浮点数。输出 A_k.shape=(512,512)。显示时使用 np.clip(A_k,0,1)，不以裁剪后矩阵计算奇异值尾和。full_matrices=False 返回约化形状；它并不意味着只计算前 k 个奇异值 [4]。

### 3.2  三通道合计公式

R、G、B 独立分解。设 T=Σ_cΣ_i σ²_(c,i)，Rₖ=Σ_cΣ_(i>k)σ²_(c,i)，则 E(k)=1−Rₖ/T，relerr=√(Rₖ/T)，MSE=Rₖ/(HWC)，PSNR=10log₁₀(1/MSE)。每通道需 Hk+k+kW 个标量，参数压缩比 CR=HW/[k(H+W+1)]。

stats(k) 直接读取奇异值平方的反向累积尾和，不重建、不逐像素相减。逆序累加避免用总能量减前缀能量产生消减误差。满秩时定义尾和为 0、理论 PSNR=∞；显式浮点重构仍可能留下约机器精度的残差。

## 5  三个关键发现及解释

### 5.1  能量陷阱

本图 k=1 的能量占比为 78.5057%，k=4 为 90.5566%，但 PSNR 仅 11.856 dB 和 15.428 dB，结构细节已经严重丢失。k=20 能量达 97.9497%，PSNR 仍只有 22.061 dB。能量是平方和尺度，大面积背景和平均亮度贡献显著；不能仅凭能量比例判断视觉质量。

### 5.2  盈亏平衡点

CR>1 ⇔ HW>k(H+W+1) ⇔ k<k*=HW/(H+W+1)。本图 k*=262144/1025=255.750244，故 k≤255 时参数更少，k≥256 时参数更多。指导书的约 353 对应另一个 620×820 尺寸，本实验不沿用该数值。

上述比较假设每个标量占相同字节。原图 uint8 原始负载 786,432 B；k=20 的因子若按 float32 保存，需 246,000 B，字节压缩比为 3.197×，而不是 12.788×。若不再量化，float32 因子的字节盈亏平衡点约为 k=63.938，从 k=64 就开始大于原始 uint8 像素负载。原 PNG 文件为 791,555 B，其大小还受到编码与元数据影响。这里未声称 SVD 优于 JPEG。

### 5.3  细节损失

![图 6  同一区域局部对照：原图、k=1、k=4、k=20](../02_实验本体/results/06_detail_crop.png)

宇航服徽章、衣服接缝和器件边缘比大块橙色区域更早变得模糊，说明该样本的细节需要更多奇异分量共同表达。小奇异值并不普遍等价于高空间频率；“高频细节先损失”是本图观察到的趋势，不是每张图的严格定理。

## 6  Eigenfaces：训练与测试设计

Eigenfaces 将一张脸展开为 D=112×92=10,304 维向量。按 Turk 与 Pentland 的共享子空间思路 [5]，对训练矩阵求均值 μ，中心化后 X_c=UΣB；B 的前 k 行作为共同基。样本系数 z=(x−μ)Bₖᵀ，重建 x̂=μ+zBₖ，分类在系数空间中使用欧氏距离最近邻。

随机种子固定为 20260917，每个人独立随机选 7 张训练、3 张测试，共 280/120 张。均值、PCA 基、量化参数只由训练集得到；测试图像不参与拟合。所有划分保存在 face_split.csv。这是已知身份的闭集识别，测试人员与训练人员相同，测试照片不同，不能解释为对未见过身份的识别能力。

主评估 k=80 在运行前固定；其他 k 用于敏感性分析，不以测试表现选择新的“最佳参数”。单次划分结果具有样本依赖性，不复述指导书的约 96% 为本次结果。

![图 7  训练集均值脸及前 11 个特征脸；基图分别归一化显示](../02_实验本体/results/08_mean_eigenfaces.png)

中心化训练矩阵数值秩为 279；特征脸正交性残差为 6.772e-14。特征脸是带正负值的空间模式，不是另外采集的真实人脸照片。

## 7  边缘设备共享基与 int8 量化

采用 k=32 的同一训练 PCA 基，按每个系数维度的训练分布 0.1% / 99.9% 分位数定义 lo、hi，并令 scale=(hi−lo)/255。编码 q=round(clip((z−lo)/scale,0,255))−128，q 为 int8；解码 ẑ=(q+128)scale+lo，再重建 μ+ẑB。没有使用测试分布标定量化器。

| 项目 | 本次实测 |
|---|---|
| 浮点系数重建 PSNR | 21.442089 dB |
| int8 系数重建 PSNR | 21.441348 dB |
| PSNR 损失 | 0.000742 dB |
| 相对浮点重建的最大像素差 | 0.021111（像素范围 0～1） |
| 测试系数超出分位范围 | 0.2344% |
| 量化后最近邻准确率 | 96.67%（训练和测试均量化） |
| 原始 uint8 / 系数帧负载 | 10,304 B / 32 B（322×） |
| 共享模型原始 / NPZ 文件 | 1,360,384 B / 1,362,124 B |
| 含共享模型的 120 帧压缩比 | 0.9064× |
| 相对原始像素的摊销盈亏平衡 | 133 帧 |

平均 PSNR 变化很小，但最大像素差达到 0.0211，明显不等于指导书示例的 0.0015。重尾样本的分位截断可能产生局部较大误差，不能仅用平均指标宣称量化没有代价。

模型原始负载包含 32×10304 个基元素、10304 个均值、32 个 lo 和 32 个 scale，均按 float32 计。总发送量为 B_model+32N；相对原始 uint8 帧节省要求 N> B_model/(10304−32)，本次至少 133 帧。该估算未计网络包头、身份元数据、加密与重传开销。

已输出实际 int8 编码、共享基与模型版本，并对模型原始字节计算 SHA-256 标识；本地加载已保存的 float32 模型解码后，与计算结果交叉核验。部署时需比对基 ID、版本和量化参数；本实验完成的是本地编解码，没有声称已部署到真实边缘设备。

系数化不是加密，也不能保证去标识化：本实验恰恰能用系数进行身份分类。持有基的一方能够近似恢复人脸；没有基也不构成可证明的隐私保护。去掉若干主分量的身份保护效果并未在本实验中验证。

### 8.1  共享基如何推广到三维

3DMM 将对应顶点的形状坐标和纹理分别展开，使用 S=μ_S+Σᵢαᵢbᵢ、T=μ_T+Σᵢβᵢcᵢ 表示 [6]。本次未获取受限真实 3D 扫描，按照数据说明允许的教学替代路径，以 Eigenfaces 验证共同数学机制，并额外构造合成曲面检验形状系数化。

### 8.2  时序模拟条件

ORL 是静态照片库，未提供连续采集的时间戳，不能把文件编号当视频顺序。因此以一个测试样本的 PCA 系数为中心，叠加振幅为各训练系数标准差 0.12 倍的平滑正弦变化，生成 300 帧、32 维模拟轨迹。量化仍使用训练参数。此构造主动满足平滑性，结论仅适用于该模拟条件。

| 直接 int8 + zlib | 1979 |
| int16 差分 + zlib | 1387 |

公平比较双方均采用 zlib：直接系数 1,979 B，差分系数 1,387 B，额外压缩为 1.427×，没有达到指导书举例的 2～3×。如果只做差分而不熵编码，int16 反而把负载扩大一倍。包含一次共享模型分发时，300 帧相对原始像素负载的压缩比为 2.270×；未计网络封装。

绝对系数刷新帧只重置预测状态，不会重算 PCA 基。本实验没有实测场景切换、姿态漂移检测或真实视频上的基更新，也没有与 JPEG/H.264 等编码器进行率失真比较，因此不能据此宣称这是唯一或普遍更好的视频压缩方式。

### 9  实验结论

（1）给定矩阵的秩、奇异值及能量结构均与设定一致；核对乘法约定是复现实验的必要步骤。
（2）低秩压缩的质量、能量与存储是不同指标；本图 k=80 达到约 30.75 dB，但按 float32 字节存储时已不比 uint8 原始负载小。
（3）共享基把单张图像表示为少量系数，同时可用于识别；基与均值的开销必须由足够多样本摊销。
（4）量化与差分编码有实测收益，也有截断误差和字节开销；真实数据结论与模拟机制验证应分别表述。
