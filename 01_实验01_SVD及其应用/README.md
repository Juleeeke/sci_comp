The experiment was rerun on 9 October 2026, and all 22 numerical assertions passed. The 5 x 4 matrix has rank 4. RGB metrics cover k=1 through 512. The primary Eigenfaces result is 118/120 correct (98.33%) on a fixed closed-set split. Real ORL photographs support the recognition and local quantization experiments. ## Reproduction

Run from this folder:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-report.txt
python 02_实验本体/run_experiment.py
python build_reports.py
bash 04_LaTeX源码/compile.sh
soffice --headless --convert-to pdf --outdir 05_Deliverables 03_最终实验报告/SVD_Report_English_Word.docx
python verify_delivery.py
```

On Windows, activate `.venv\Scripts\activate` instead. Word can also export the DOCX to PDF. The provided Word PDF was generated by LibreOffice; a new export in another application can change pagination and should be checked.

`compile.sh` searches for Tectonic, a compiler selected with `CODEX_TECTONIC_PATH`, or the bundled macOS Tectonic. On another platform, run `tectonic main.tex` inside `04_LaTeX`, then copy the PDF to the deliverables folder. The current LaTeX source uses Times New Roman and Courier New from macOS system paths; adjust the two `fontspec` lines for another operating system. Initial compilation may fetch official TeX packages. Runtime scientific-library versions are saved in the experiment lock file and run summary.

The exact original data are included, so numerical reruns do not require downloading datasets. Cached generated OMML in `03_最终实验报告/equations.json` lets the current report rebuild without Microsoft Word. If mathematical formulas are changed, cache regeneration additionally uses the installed Microsoft Word `mathml2omml.xsl`; the stylesheet is not redistributed. The builder normalizes delimiters and checks preservation of all alphanumeric and minus tokens during conversion.

Updating blank personal fields requires only editing the DOCX and re-exporting its PDF. The measured experiment need not be rerun.

## Integrity and validation

`manifest_sha256.csv` records file hashes. `verify_delivery.py` checks the exact final PDFs, their English content, all detailed paragraphs, page bounds, blank identity fields, Office equations, Word package integrity, original-source hashes, and numerical evidence. All final pages were rendered and inspected; representative equations and reference pages were also inspected at higher resolution. The nonfatal Tectonic `lineno.sty` encoding warning did not result in a replacement character in either final PDF.
