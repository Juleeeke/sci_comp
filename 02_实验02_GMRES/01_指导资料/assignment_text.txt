Lab 2: Applying the GMRES Method to Large Sparse Linear Systems
【Class Hours】 2 class hours 【Objectives and Requirements】 Through this lab, students will
become further familiar with using AI on a personal computer to write, debug, run, and analyze results
of Python code; become familiar with the GMRES method and the incomplete LU (ILU) preconditioning
technique for solving large sparse linear systems, and compare them with the Gauss–Seidel iteration,
so as to understand the applicability and efficiency of these algorithms; and try to use these methods
to solve a two-point boundary value problem.
【Notes】 \begin{itemize} \item[1、] Pay attention to the difference between the computational
expressions of Python code and their mathematical written form. \item[2、] Observe the differences
between the results produced by AI-assisted programming and those given by the Python–NumPy
library functions. \end{itemize}
