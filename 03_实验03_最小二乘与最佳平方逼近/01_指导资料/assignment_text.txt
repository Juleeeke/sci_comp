【Class Hours】 2 class hours 【Objectives and Requirements】 Through this lab,
students will become further familiar with using AI on a personal computer to
write, debug, run, and analyze results of Python code; become familiar with the
least squares method for solving overdetermined linear systems and for fitting
discrete data (both linear and nonlinear models), and with the best square
approximation of continuous functions using orthogonal bases (including
Legendre polynomials), so as to understand the applicability and numerical
behaviour of these algorithms; and try to use these methods to fit real data (the
U.S. population growth data and the RAE2822 airfoil geometry).
【Notes】
1. Pay attention to the difference between the computational expressions of
Python code and their mathematical written form.
2. Observe the differences between the results produced by AI-assisted
programming and those given by the Python–NumPy library functions.
